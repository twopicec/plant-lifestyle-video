# Plant Lifestyle Video Skill

一个面向中文植物与家居生活短视频的 Codex skill。它把现有素材组织成有故事、有生活感、轻松又实用的成片，而不是按拍摄顺序做成流水账。

## 能做什么

- 检查本地视频、音频和已有成片
- 设计短视频故事线、口播和剪辑节奏
- 制作或校对时间轴字幕
- 自然修音与情绪调整
- 规划音乐、音效、花字和检查版
- 延续封面视觉风格
- 生成适合小红书、兼顾抖音的标题与正文

## 安装

在 Codex 中让它从本 GitHub 仓库安装该 skill，或手动克隆到个人技能目录：

```bash
git clone https://github.com/sunyao0115-create/plant-lifestyle-video.git ~/.codex/skills/plant-lifestyle-video
```

## 使用

```text
使用 $plant-lifestyle-video，根据我现有的植物素材，完成策划、口播、剪辑、声音、封面和发布文案。
```

也可以只处理其中一个阶段，例如：

```text
使用 $plant-lifestyle-video，听最终口播并制作不改变时间的无标点字幕。
```

```text
使用 $plant-lifestyle-video，按照已有封面风格为这条植物视频制作封面。
```

## 设计取向

这个 skill 偏向“家居生活里真实发生的植物故事”：保留小意外、动作原声和个人语气，同时让观众自然带走两三个实用判断。它不会虚构缺失镜头，也不会默认覆盖原始文件。
